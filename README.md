## Projects

### ⚽ [gambeta.ai](https://gambeta.ai/en)

AI-generated sports predictions with a publicly auditable track record, in 18 languages. Over 8,000 registered users. Runs on Cloudflare Workers and Pages with Supabase.

Co-founder and technical lead. I led the v2 redesign, took the mobile PageSpeed score from 37 to 92, ran the security audit and hardening, and set up the project's agent tooling in Claude Code.

### 📷 [Fototeca La Pelada](https://fototecalapelada.com.ar/en) · [code](https://github.com/guidotesolin/fototeca-la-pelada)

Digital photo archive of the town of La Pelada, Santa Fe: over 700 historical photographs with full-text search, a permalink per photograph, and an interface in four languages. An admin panel lets the archive's authors edit, translate, and publish without touching code. Scores 100 in all four Lighthouse categories on mobile and desktop. Non-profit, MIT license.

Next.js, React Server Components, TypeScript, PostgreSQL, Drizzle ORM, Cloudflare R2, Vercel.

### 💸 [Evenly](https://github.com/guidotesolin/evenly)

Android household finance app that replaced a couple's budget spreadsheet: monthly fixed costs with their US dollar equivalent, shared expenses split evenly, and a real-time balance. No server code: the business rules live in SQL, protected by Row Level Security. Infrastructure cost of USD 0 per month.

React Native, Expo, TypeScript, Supabase, PostgreSQL.

### ⚖️ [SV & Asociados](https://estudiovidoni.com.ar/) · [code](https://github.com/guidotesolin/sv-estudio-juridico)

Website for a law firm in Santa Fe. A visitor sees what the firm can do for their case, gets an indicative fee from a four-step estimator, and books a paid consultation on their own. Static site with a strict Content Security Policy and no personal data stored.

Astro, TypeScript, Cal.com, Cloudflare Pages.
